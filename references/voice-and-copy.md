# Voice and copy

## Register

Calm. Institutional. Short. Saudi-aware. Outcome-focused.

Write as a strategist handing a brief, not as an influencer launching a personal brand.

## English

- Sentence case
- Short sentences
- Concrete nouns
- No hype stack (“unlock”, “game-changing”, “crush it”, “journey”)
- Use the relevant official property: MohammadBahareth.com (primary), MohammadBahareth.sa, Bahareth.com.sa, Dyslexia.sa, or Space.org.sa as appropriate to context

## Arabic

- Modern Standard Arabic only (فصحى)
- No Egyptian dialect, slang, or sarcastic colloquial
- No mixed-script jokes inside official lockups
- RTL paragraphs with native direction
- Keep URL, email, `©`, and English legal phrases LTR

## Allowed on visual lockups

- Mohammad Bahareth / محمد باحارث
- Best Selling Author
- Business Consultant of the Year
- Creator of the Goal Model Canvas™
- Relevant official property URL
- Copyright line
- Concise verified descriptors (dyslexia advocate, space advocate) when channel-appropriate and confirmed

## Not allowed on visual lockups

- Unheld offices
- Government relationships
- Client lists
- Extra unconfirmed awards
- Follower goals
- Romantic or influencer language
- Invented slogans unless the user supplies one for that artifact

## Professional bio (separate track)

If the user asks for a market-entry bio, private advisory positioning, or longer copy rather than a cover lockup, use verified commercial positioning from official properties and independent sources (Saudi market-entry work, frameworks such as Goal Model Canvas™ / Bahareth Method™ / Deal Maker™, dyslexia advocacy via Dyslexia.sa, space work via Space.org.sa). Keep claims factual. Do not merge detailed bios into PDF cover bylines unless the user overrides.

Cross-check key numbers (consultations, published works, certifications) against official properties and public records. Prefer multi-source confirmation.

## Public generated-content footer

For X / news-style generated posts the user publishes, keep `@mbahareth` and the required AI-disclosure line the user already uses on that channel. Print PDFs use the copyright lock instead.
