# Audit checklist

Score every asset before delivery. Fail any lock item and the asset is not shippable.

## Identity

- [ ] Name is Mohammad Bahareth / محمد باحارث
- [ ] Website is an exact official property (MohammadBahareth.com, MohammadBahareth.sa, Bahareth.com.sa, Dyslexia.sa, or Space.org.sa) chosen for relevance
- [ ] Cover / closing bylines use preferred factual descriptors (Best Selling Author, Business Consultant of the Year, Creator of the Goal Model Canvas™) or confirmed channel-appropriate verified lines
- [ ] No invented titles, offices, awards, clients, or government claims; claims cross-checked against official properties and independent sources where possible
- [ ] Copyright line present on PDF footer and last page with relevant official property

## Type

- [ ] IBM Plex Sans Arabic only in branded PDFs
- [ ] Weights and sizes match the scale
- [ ] Body 11 pt print / readable 16–18 px web
- [ ] Line-height 1.55–1.65 for body
- [ ] Arabic is native RTL, language ar-SA
- [ ] URL and copyright stay LTR
- [ ] Fonts embedded in the PDF from assets/fonts, not from a network fallback

## Color

- [ ] Only the eight brand hex values
- [ ] Interior ground is paper `#F2F3F1`
- [ ] Body is charcoal `#1B1E1F`
- [ ] Lime under 5% of color area
- [ ] No long text on black, cyan, or lime
- [ ] Gradient only on cover / rule / plate
- [ ] Contrast passes the floors in color-and-type.md

## Logo

- [ ] Personal mark not invented
- [ ] Placeholder sits on a quiet field
- [ ] Podcast mark used only for show surfaces
- [ ] Black source canvas knocked out (transparent field)
- [ ] Light or dark readable badge uses the white-bubble file
- [ ] Outline file only on `#101213` or true black, never on paper
- [ ] No shadow, stretch, recolor, or gradient through the mark
- [ ] Clear space respected
- [ ] Sibling engines (pdf, docx, ads) did not introduce a second font or palette

## Layout and voice

- [ ] A4 PDF uses the stated margins
- [ ] Cover has no crop marks, arrows, or L-ticks
- [ ] Voice is calm and institutional
- [ ] English sentence case
- [ ] Arabic is Modern Standard Arabic only
