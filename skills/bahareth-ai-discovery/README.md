# Bahareth AI Discovery & Authority

A no-lock-in, evidence-centered Agent Skill for coordinating technical SEO, GEO, content trust and real sampled AI-answer visibility across four independent sites. It lives in its own directory and does not modify the existing top-level Mohammad Bahareth Brand skill.

## Quick start

Open SKILL.md in an Agent Skills-compatible assistant.

Run:
- python3 -m src.cli audit profiles/space.org.sa.json
- python3 -m src.cli audit profiles/mbahareth.pub.sa.json
- python3 -m src.cli visibility profiles/mohammadbahareth.com.json examples/observations.json
- python3 -m unittest discover -s tests -v

Python 3.10+, standard library only. HTTP audit uses public HTTPS GET, restricted to the chosen host. No editing, publishing, authentication, API-provider keys or background monitoring.

## Distinct outcomes

- Global site: speaking, interviews, authority, selected professional opportunities.
- Publishing site: correct editions, purchases, distribution and film/TV rights.
- Saudi site: institutional Arabic visibility, workshops, media and speaking.
- Space site: indexing recovery, scientific data provenance, aerospace research and partners.

Search accessibility is NOT evidence that an AI recommended this brand. Genuine timestamped provider responses must be supplied separately. Sample observations are synthetic and always return not_measured.

The implementation incorporates patterns from public SEO/GEO projects without copying their code. See references/INTEGRATIONS.md.
