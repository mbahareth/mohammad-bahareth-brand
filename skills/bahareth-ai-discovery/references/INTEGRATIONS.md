# Conflict-free architecture and upstream study

## Five independent layers

1. Domain scope and brand policy: exactly one approved target, no cross-project writes.
2. Collection: public HTML, origin headers, approved repo data and original source documentation.
3. Specialized evidence reviewers: technical SEO, claim validation, bibliographic rights, Saudi institutional accuracy, aerospace data.
4. Measurement: SEO technical signals, actual provider responses/citations, real leads and sales, each separately reported.
5. Controlled delivery: immutable backup, minimal diff, QA, owner authorization and rollback.

## Conflict-resolution rules

- One active domain per run and one person in charge of deployment. Cross-domain identity links are read-only.
- Existing approved domain-specific brand tokens beat generic recommendations; root official brand skill governs identity.
- If book rights are disputed or undocumented, show inquiry subject to verification, not an available-for-sale license.
- Government links are not institutional endorsement.
- Research-stage concepts are not current deployed satellite or mining capabilities.
- No fake testimonials, press coverage, scientific values, KDP editions or ranking claims.
- Search-ready pages never equal model citation share. Unknown remains unknown.
- Never automatically install paid services, scrape private data, or accept third-party scan results as authoritative.
- All third-party packages must have their present licenses verified before optional code integration. Nothing upstream is vendored here.

## Output envelope

Every finding: source_tool, host, url, observed_at, check, observed_value, severity, confidence, repro_steps, responsible_owner, next_action, verification_test.

Every AI observation: unique id, engine, model, query, locale, captured_at, response, cited URLs. Keep sensitive answers private.
